An entry for [Fridge Roast: One Line, Biggest Laugh](https://make.fun/competitions/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb) on make.fun.

`main.ts` writes a single roast line — at most 200 characters, roasting a smart
fridge — to `/output/entry.txt`. It is fully deterministic: the same line on
every run, with no randomness and no network access.

Run it with Node 22.18 or later:

```sh
node main.ts
```
